# Personal Project Showcase

## Overview

The **Personal Portfolio Showcase** is a Single Page Application (SPA) built with React that allows users to browse, search, and manage a collection of web development projects. The application demonstrates modern React concepts, including component-based architecture, state management with hooks, event handling and dynamic rendering.

This project was developed as part of a React summative assessment to showcase frontend development skills and best practices.

---

## Features

* Display a list of projects
* Search projects by title
* Add new projects dynamically
* Responsive and user-friendly interface
* Reusable React components
* State management using React's `useState` hook
* Clean and modern portfolio design

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/your-repository-name.git
```

2. Navigate into the project folder:

```bash
cd your-repository-name
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser and visit:

```text
http://localhost:5173
```

---

## How to Use

* Browse the existing projects displayed on the homepage.
* Use the search bar to filter projects by title.
* Complete the "Add New Project" form to add a project dynamically.
* Newly added projects appear immediately without refreshing the page.
